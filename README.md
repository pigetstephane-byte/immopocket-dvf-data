# ImmoPocket — données DVF

Ce dépôt public contient uniquement le socle de données **DVF/DGFiP**, lui-même public, utilisé par ImmoPocket pour Saint-Raphaël, Fréjus et Roquebrune-sur-Argens.

- Source : [DVF géolocalisées sur data.gouv.fr](https://www.data.gouv.fr/datasets/demandes-de-valeurs-foncieres-geolocalisees)
- Périmètre : maisons et appartements vendus dans les trois communes
- Synchronisation : hebdomadaire et déclenchable manuellement
- Secrets ImmoPocket : aucun
- Code de l’application ImmoPocket : absent de ce dépôt

Les fichiers produits sont `data/dvf_83.duckdb` et `data/dvf_metadata.json`.
